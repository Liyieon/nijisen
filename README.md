# 虹線 NIJISEN · 01 — Video Threshold Sequencer

導入影片 → 在畫面上放 threshold line → 影像變化碰到線就觸發音高 → 觸線瞬間的頻譜印成一張圖。

**線上版：https://liyieon.github.io/nijisen/**

虹線 NIJISEN 規劃成一個容納多種音像互動視覺工具的站台，這是第一個模組（module 01）。純前端，影片不上傳，全部在瀏覽器本機運算。

---

## 啟動

**必須用本機 http 伺服器開**（直接雙擊 `index.html` 會因為 file:// 的 canvas 安全限制讀不到影片像素）。

```bash
python -m http.server 8765
```

然後開 http://localhost:8765/index.html

Windows 也可直接雙擊 `start.bat`。

### 手機

直接開 https://liyieon.github.io/nijisen/ 。畫面在最上方，底下依序是播放列、頻譜圖版，最下面是控制面板的 dock；面板會從底部彈出。旋鈕一樣上下拖曳操作。

iOS / Android 都要先點畫面任一處才會發聲（瀏覽器的自動播放限制），載入影片後點一下即可。

---

## 操作流程

1. 把影片拖進畫面，或按 **選擇影片**；要用自己的動作演奏就按 **使用攝影機**。
2. 音訊預設開啟。瀏覽器要求先有一次點擊才會發聲，任何一次點擊都會自動啟動；左上角的圓點是綠色就代表有聲音在出來。
3. **拖曳畫面上的白線**移動偵測位置（上下鍵微調）。
4. 影像穿過線時會觸發音符，觸線瞬間的頻譜會印在下方的 **頻譜圖版**。
5. 要調整參數時，從左側 dock 打開對應的面板。

### 快捷鍵
| 鍵 | 功能 |
|---|---|
| `Space` | 播放 / 暫停 |
| `1` `2` `3` | 音色：鐘聲 / 撥弦 / 故障 |
| `↑` `↓` | 微調選取的線 |
| `Tab` / `Shift+Tab` | 循環選取線 |
| `Delete` | 刪除選取的線 |
| `F` | 進出演出模式 |
| `P` | 顯示 / 收起頻譜圖版 |
| `R` | 開始 / 停止錄製 |
| `C` | 開關攝影機 |
| `L` | 演出模式中開關偵測線 |
| `Esc` | 關閉面板；演出模式中離開 |

## 介面

整個畫面以影片（或攝影機）為主，其他控制都是浮在上面的玻璃元件，平常只露出最少的東西：

| 位置 | 內容 |
|---|---|
| 左上膠囊 | 名稱、目前的影片、狀態（待機 / 播放中 / 暫停 / ● 錄製 00:12）、音訊燈號 |
| 右上膠囊 | 預設組合（◀ 標準 ▶）、隨機、淺色 / 深色、演出模式 |
| 左側 dock | 五個面板：來源 · 偵測線 · 聲音 · 顏色 · 輸出 |
| 畫面下方 | 播放列：播放、時間軸、重複播放、圖版開關、錄製 |
| 最下方 | 頻譜圖版（玻璃條，可收起） |

背景是影片本身的顏色縮小後模糊而成，玻璃面板底下透出的就是畫面的色彩；沒有載入影片時是一片柔和的色彩。

### 彈出面板
- 一次只開一個。按 `Esc`、右上角 ×、再按一次 dock 按鈕，或點面板外面都會關閉
- **點畫面不會關閉面板**：可以一邊開著面板調參數，一邊拖曳偵測線
- 手機上面板改成從底部彈出

### 旋鈕
每顆旋鈕都寫著名稱、縮寫、目前的數值與單位，底下一行說明它在調什麼。

- **上下拖曳**改值（按住 `Shift` 微調）、**滾輪**逐格調、**雙擊**回到預設值
- 用 Tab 移到旋鈕上後，**方向鍵**調整、`PageUp` / `PageDown` 大步調整、`Home` 回到預設值

### 來源
`選擇影片檔` · `攝影機` 開關 · 鏡頭切換（手機可切前後鏡頭）· 鏡像（左右翻轉 / 原始方向）· 影片原聲開關。

### 偵測線
| 控制 | 意義 |
|---|---|
| 偵測什麼 | `動態` 前後兩幀的差異 · `亮度` 越過門檻 · `邊緣` 邊緣穿越 |
| 線 | `＋ 橫線` · `＋ 直線` · `刪除選取`（最多 8 條，可以全部刪光） |
| 選取 | 左右箭頭循環選取；也可以直接點畫面上的線 |
| 靈敏度 SENS | 越低越容易觸發 |
| 格數 CELLS | 每條線切成幾格 = 幾個音高（橫線左低右高；直線上高下低） |
| 間隔 HOLD | 同一格再次觸發的最短時間 (ms)，防止機關槍 |
| 取樣寬度 BAND | 線上下各看幾個像素 |

面板下方的 **每一格的活動量**：柱子超過虛線就會觸發，下緣的方塊是剛剛觸發的格子，右上角是選取線的峰值與觸發格數。

### 聲音
- **音色**：`鐘聲` 2-op FM 玻璃質感長尾音 · `撥弦` Karplus-Strong 撥弦 · `故障` 破音方波 + bitcrush + 掃頻帶通
- **音階**：小調五聲 · 大調五聲 · 多利安 · 全音 · 半音
- **節拍對齊**：不對齊 · 4 / 8 / 16 / 32 分音符（觸發會對齊到 BPM 格線）
- **旋鈕**：根音 ROOT · 速度 BPM（同時決定延遲時間）· 音量 VOL
- **效果**（可以同時開好幾個）：殘響 · 延遲（附點八分）· 低通 · 位元破壞 · 低八度
- 面板右上的 `試聽` 用目前的音色試奏五個音；`音訊開 / 關` 關掉時只印圖不發聲

### 顏色
七組掃描線配色：`SPECTRUM`（12 色全色相彩虹）· `CYANO`（藍晒）· `STEEL` · `NEON` · `EMBER` · `MONO` · `PAPER`（淺色，適合深色影片）。

**畫面上的線與頻譜圖版用同一組顏色。** 自訂顏色可以 `套用到全部` 或 `只套用選取的線`；`清除自訂顏色` 回到目前的配色。

### 輸出
**錄製**
- `聲音 WAV`：錄下主輸出（含殘響、延遲、壓縮後的最終聲音），停止後自動下載 16-bit / 48kHz 立體聲 WAV
- `影片`：把畫面、偵測線、頻譜圖版合成一支檔案，連同聲音一起錄；瀏覽器支援就存 **mp4（H.264 + AAC）**，否則存 webm
  - `畫面＋圖版`：橫式圖版接在下方、直式圖版放在右側；`只有畫面` 只錄影片與偵測線
  - 演出模式中隱藏偵測線時，錄出來的影片也不會有線
- 播放列的紅色圓鈕與面板裡的 `開始錄製` 是同一個開關；錄製中左上狀態會變紅並計時

**MIDI 輸出**
- 按 `MIDI` 啟用（瀏覽器會詢問權限），左右箭頭切換輸出裝置
- 每次觸發送出 note on + note off，**與內建音色落在同一個量化時間點**；音訊關閉時照樣送 MIDI
- `同一頻道`（左右箭頭選 1–16）或 `每條線一個頻道`（第 N 條線走第 N 頻道，方便在 DAW 分軌）
- `音符長度` 60 / 140 / 400ms；`全部停止` 對 16 個頻道送 all notes off
- 需要 Chrome / Edge / Firefox；Safari 與 iOS 目前不支援 Web MIDI

**分享與保存設定**
- `複製分享連結`：把全部設定編進網址並複製。影片檔本身不會包含在內；改版前做的舊連結一樣能開
- `存成檔案` / `載入檔案`：匯出 / 匯入 `.json` 設定檔
- `自動保存`：預設開啟，重新整理會回到上次設定。網址中的分享設定優先
- 分享連結被當作不可信輸入：每個欄位都經過白名單或數值範圍檢查，顏色只接受 `#rrggbb`

### 頻譜圖版
- `捲動` 時間由左往右捲動 · `疊印` 印在被碰到的那一格位置，反覆疊印 · `環形` 極座標，角度 = 線上的位置
- `自動 / 橫 / 直` 版面：自動依影片長寬比切換（高度 > 寬度 × 1.05 判為直式）；直式影片時圖版站到畫面右側，時間改為由上往下
- `清除` · `存成 PNG`；播放列的圖版按鈕（或 `P`）可以把圖版收起，讓畫面更大
- 顏色取自影片被碰觸位置的實際像素色，再吸附到掃描線配色

### 演出模式
按右上角的全螢幕按鈕（或 `F`）：所有控制都隱藏，只留**畫面、偵測線與頻譜圖版**，並請求瀏覽器全螢幕。

- 用快捷鍵操作：`Space` 播放 · `L` 開關偵測線 · `P` 圖版 · `R` 錄製 · `F` 或 `Esc` 離開
- 隱藏偵測線時**仍持續偵測與發聲**，只是看不到、也無法拖曳；離開演出模式後一律顯示
- 線段照樣可以拖曳、選取

### 深色模式
右上角的半圓按鈕切換淺色 / 深色。頻譜圖版跟著換底：淺色用 `multiply`（墨壓在紙上），深色用 `screen`（光印在暗底上）；切換時圖版會重新鋪底。

### 攝影機
- 需要 **https 或 localhost**（`start.bat` 開的 `http://localhost:8765` 可以，GitHub Pages 也可以；`file://` 不行）
- 即時輸入沒有時間軸，所以時間軸與重複播放會變淡，時間顯示改為 `即時 已進行時間`
- 載入影片檔會自動關閉攝影機並釋放鏡頭；畫面只在本機運算，不會上傳

## 疑難排解

左上膠囊最右邊的圓點是音訊狀態（滑鼠移上去會顯示文字）：
- 綠色：正常發聲
- 琥珀色：AudioContext 還沒被使用者手勢啟動 → 點畫面任一處
- 空心：你自己關掉了 → 打開「聲音」面板，按 `音訊開`

沒聲音先按「聲音」面板的 `試聽`。有聲 = 音訊路徑正常，問題在偵測參數（SENS 太高、HOLD 太長、線的位置沒東西經過）；沒聲 = 檢查系統音量與分頁靜音。
