# 虹線 NIJISEN · 01 — Video Threshold Sequencer

導入影片 → 在畫面上放 threshold line → 影像變化碰到線就觸發音高 → 觸線瞬間的頻譜印成一張圖。

**線上版：https://liyieon.github.io/nijisen/**

虹線 NIJISEN 規劃成一個容納多種音像互動視覺工具的站台，這是第一個模組（module 01）。純前端，影片不上傳，全部在瀏覽器本機運算。

---

## 啟動

**必須用本機 http 伺服器開**（直接雙擊 `index.html` 會因為 file:// 的 canvas 安全限制讀不到影片像素）。

```bash
python -m http.server 8765
```

然後開 http://localhost:8765/index.html

Windows 也可直接雙擊 `start.bat`。

### 手機

直接開 https://liyieon.github.io/nijisen/ 。版面會自動改為單欄捲動：影片在最上、參數與頻譜圖版接在下方、左右控制欄轉成可橫向滑動的長條。旋鈕改用上下拖曳操作，時間軸點按即跳轉。

iOS / Android 都需要先點畫面任一處才會發聲（瀏覽器的自動播放限制），載入影片後點一下即可。

---

## 操作流程

1. 點畫面中央（或直接拖影片進去）載入 mp4 / webm / mov。
2. 音訊預設開啟；瀏覽器規定要有一次點擊才會發聲，任何一次點擊都會自動啟動（也可按 **TEST** 立刻確認）。
3. 用滑鼠**拖曳畫面上的白線**移動 threshold 位置（上下鍵可微調）。
4. 影像穿過線時 → 觸發音符 + 在下方 SPECTRUM PLATE 印出頻譜。
5. 按 **PNG** 或 **IMG** 匯出那張圖。

### 快捷鍵
| 鍵 | 功能 |
|---|---|
| `Space` | 播放 / 暫停 |
| `1` `2` `3` | 切換音色 BELL / PLUCK / GLITCH |
| `↑` `↓` | 微調選取的線 |

## 面板說明

### 上排
每顆按鈕是一塊**指令面板**：切角外框、左側狀態 LED、右上角編號碼。

- 常態鈕（`CLR` `RND` `IMG` `TEST` `PLAY` `FILE` `PNG`）按下時 LED 閃一下
- 開關鈕（`AUDIO` `SRC` `LOOP`）開啟時整塊反白填墨，LED 亮起對應色
- LED 顏色即功能色：綠 = 發聲/輸出、琥珀 = 隨機/檔案、藍 = 訊號、紅 = 清除

`AUDIO` 音訊開關（預設已開）· `CLR` 清除頻譜圖 · `RND` 隨機參數 · `IMG` 匯出 PNG · `SRC` 影片原聲開關 · `TEST` 試奏五個音

**PRESET 步進器**取代下拉選單：左右箭頭切換，右側四顆 pip 顯示目前位置（default / rain / glass / broken）。

### 版面模式（LAYOUT）
右上角 `AUTO / LAND / PORT` 三檔：

- `AUTO`（預設）依影片長寬比自動切換：高度 > 寬度 × 1.05 判為直式
- `LAND` 橫式 — 影片佔滿上方，參數列與頻譜圖版橫躺在下
- `PORT` 直式 — 影片維持全高靠左，參數列與頻譜圖版收成右側直立控制台，頻譜圖版轉為直幅

手動選過之後就固定不再自動切換；要恢復自動判斷按 `AUTO`。切換版面時頻譜圖版會等比重繪，畫好的圖不會消失。

### 左側菱形（SCL / QNT）
菱形內嵌一圈細框，選中時填墨、內框轉為該檔的專屬色，背後有一條 HUD 匯流線串起整組。

- 上組 = **音階**：PENT(小調五聲) / MAJ(大調五聲) / DOR(多利安) / WHOLE(全音) / CHRM(半音)
- 下組 = **量化**：FREE(不量化) / 4n / 8n / 16n / 32n — 觸發會對齊到 BPM 網格

### 右側圓形（VCE / FX）
每顆圓鈕外圈是刻度環：音色 32 刻、效果 24 刻。啟用時填墨並亮起彩色環，音色鈕內部另有各自齒比的螺旋紋。

- 上組 = **三組音色**
  - `BELL` 2-op FM，玻璃質感，長尾音
  - `PLUCK` Karplus-Strong 撥弦模型
  - `GLITCH` 破音方波 + bitcrush + 掃頻帶通，短促
- 下組 = **效果**：`REV` 殘響 · `DLY` 附點八分延遲 · `LPF` 低通 · `BIT` 位元破壞 · `SUB` 低八度疊加

### 參數列（旋鈕）
所有連續參數都是旋鈕，不用 slider：
- **上下拖曳**改值（按住 `Shift` 微調）
- **滾輪**逐格調
- **雙擊**回到預設值


| 參數 | 意義 |
|---|---|
| DETECT | `MOTION` 幀差（動態變化）／`LUMA` 亮度越過門檻／`EDGE` 邊緣穿越 |
| SENS | 靈敏度門檻，越低越容易觸發 |
| CELLS | 線被切成幾格 = 幾個音高（左低右高；垂直線上高下低） |
| HOLD | 每格的最短重觸發間隔 (ms)，防止機關槍 |
| BAND | 取樣帶寬度（線上下各幾 px） |
| ROOT | 最低音（根音） |
| BPM | 量化網格速度，同時決定 delay 時間 |
| VOL | 主音量 |
| LINES | `+H` 加橫線 · `+V` 加直線 · `DEL` 移除（最多 6 條） |

### 掃描線：選取 · 刪除 · 上色
線段可以**被選取**，操作都針對選取中的那一條：

- **點畫面上的線**即選取（選取中的線會加粗、換成該線的掃描色、取樣帶變亮）
- `◀ ▶` 或 `Tab` / `Shift+Tab` 循環選取
- `DEL SEL` 或 `Delete` / `Backspace` **刪除選取中的線**（不再只能從最新那條刪）
- 線段**可以全部刪光**，也可以只留一條直線；最多 8 條
- `+H` / `+V` 新增後會自動選取新線

### SCAN COLOUR 掃描線顏色
七組預設：`SPECTRUM`（全色盤循環）· `CYANO`（藍晒）· `STEEL`（鋼灰）· `NEON` · `EMBER` · `MONO`（單墨）· `PAPER`（淺色，適合深色影片）。

右邊色塊是**自訂顏色**，`ALL / SEL` 決定套用到全部線或只套用選取那條。`RESET` 清掉所有自訂色、回到目前預設。

**掃描線與 SPECTRUM PLATE 共用同一組顏色**：換配色時，畫面上的掃描線與圖版上印出來的頻譜會同時改變。選取單線並指定自訂色時，該線觸發印在圖版上的也是那個顏色。

### CELL ACTIVITY 計數表
右側藍色計數條 = 每一格目前的活動量（越高條越多、越實）；紅色虛線 = 目前 SENS 門檻，條超過虛線就會觸發；下緣黑色方塊 = 剛剛觸發的格子。右上角讀數為 `L<線號> PK <峰值> / HOT <觸發格數>`。

### STAGE 全屏演出模式
按頂欄 `STAGE`（或鍵盤 `F`）進入：畫面只留**影片與掃描線**，其餘 UI 全部隱藏，並自動請求瀏覽器全螢幕。

- 畫面同時保留**影片、掃描線、SPECTRUM PLATE**（圖版收在下緣，桌機 25vh、手機 34vh）
- 浮動列上的 `PLATE` 可關掉圖版，影片就撐滿整個螢幕
- 線段照樣可以拖曳、選取
- 底部一條半透明浮動列（滑鼠移上去才變清楚）：`EXIT` `PLAY` `+H` `+V` `DEL` 與選取切換
- `ESC` 或 `EXIT` 或再按一次 `F` 離開
- 手機同樣可用，浮動列會自動換行並維持全不透明

### 深色模式
右上 `THEME` 切換 `LIGHT / DARK`。深色不是把顏色反相而已：

- 文字對比實測最低 7.18:1（小標籤），內文 15.29:1，全部超過 WCAG AA
- 色盤整體提亮（例如 riso 藍 `#3f6fa8` → `#6ba8e0`），在深底上仍看得出色相差異
- 填色控件反轉為「淺底深字」，維持與淺色模式一致的閱讀邏輯
- 紙紋改用 `screen` 混合，纖維在深底上是微亮而非發黑
- **頻譜圖版跟著換底**：淺色用 `multiply`（墨壓在紙上），深色用 `screen`（光印在暗底上），實測深色圖版 47432 個亮筆觸、0 個暗筆觸
- 切換主題會重新鋪底，圖版上已畫的內容會清空（切換時會提示）

### 時間軸
底下的刻度帶不是 slider：點擊或拖曳任一位置即跳到該時間，藍色計數條為已播放長度。

### SPECTRUM PLATE（頻譜生成圖）
- `SCROLL` 時間由左往右捲動，每幀一欄
- `STACK` 頻譜印在「被碰到的那一格」的 x 位置上，反覆疊印
- `RING` 極座標，角度 = 線上的位置

顏色取自影片被碰觸位置的實際像素色，再吸附到系統色盤，所以圖會保留影片的顏色記憶。

## 疑難排解

底部狀態列右端會顯示音訊狀態：
- `AUDIO LIVE` 正常發聲
- `AUDIO ARMED / SUSPENDED (點畫面啟動)` AudioContext 還沒被使用者手勢啟動 → 點畫面任一處
- `AUDIO OFF` 你自己關掉了 → 按左上 `AUDIO ON`

沒聲音先按 `TEST`。有聲 = 音訊路徑正常，問題在偵測參數（SENS 太高、HOLD 太長、線的位置沒東西經過）；沒聲 = 檢查系統音量與分頁靜音。

## 已驗證
- 三組音色離線渲染皆穩定收斂（4 秒尾端振幅 = 0），峰值 0.2–0.8
- 實機經 master 匯流排量測峰值 100 / 87 / 61（滿刻度 128），24 音齊發壓力測試 103，無削波
- 偵測器對合成測試影片 2 秒內產出 16 個事件，取樣到正確像素色
- 頻譜圖三模式皆有輸出，PNG 匯出正常
- 旋鈕拖曳實測改值（SENS 0.18 → 0.51）、preset 切換會回寫旋鈕（CELLS → 36）
- 時間軸、活動計數表、螺旋紋、散點場皆實測有像素輸出
- 全頁 **0 個可見 slider、0 個可見下拉選單**（原生元件僅作為隱藏狀態載體）
- 11 顆按鈕、8 個刻度環、7 顆旋鈕皆掛載成功
- 步進器四檔循環含頭尾回繞正確，會同步套用參數（rain → CELLS 28、glass → LUMA、broken → GLITCH）
- 菱形/圓鈕點擊改變狀態並套用（DOR / FREE / PLUCK / LPF）
- 掃描色：MONO 時畫面彩色像素為 0，SPECTRUM / CYANO / NEON 各產生約 40 種飽和色；自訂色只套用選取線、RESET 全部歸零
- 圖版同步：EMBER 印出 100% 暖色像素、CYANO / NEON 100% 冷色，證明圖版確實跟著掃描配色走
- 深色模式：19 個文字元件在兩種主題下對比皆 ≥ 4.5:1（深色最低 7.18:1）
- STAGE 帶圖版：桌機影片 1440×675 + 圖版 1412×204；手機 375×536 + 圖版 355×259；`PLATE` 關閉後影片撐滿
- 線段：新增後自動選取、`DEL SEL` 刪的是選取那條、可刪到 0 條、可只留直線；空欄位時偵測與繪製不出錯
- STAGE 模式：影片區撐滿 1440×900（手機 375×812），其餘 UI display:none，模式內拖曳線段位移精確（拖 20% → pos +0.200）
- 版面模式：AUTO 對直式影片切 PORT、對橫式切 LAND；手動選擇會固定不被覆蓋；按 AUTO 可恢復
- 1920×1080 橫式影片區 1692×579、直式 1274×928；1280×720 亦無溢出
- 修正三處版面 bug：頂欄 grid 被左側按鈕撐爆（改 flex）、`.spiro` canvas 未給寬高而以 72px 內在尺寸溢出圓鈕、`.viewport canvas` 泛用規則把載入標記拉成 390×98（改用子選擇器，回到 74×74）

> 註：瀏覽器分頁在背景時 `requestAnimationFrame` 停止，偵測與繪製迴圈跟著停 — 分頁需保持前景。
